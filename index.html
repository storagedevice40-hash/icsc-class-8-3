4. Verify the associative law of addition for the following groups of rational numbers.
(i) $\frac{1}{2}, \frac{-2}{3}$ and $\frac{1}{5}$
Solution:
$\left(\frac{1}{2} + \frac{-2}{3}\right) + \frac{1}{5} = \left(\frac{3 - 4}{6}\right) + \frac{1}{5} = \frac{-1}{6} + \frac{1}{5} = \frac{-5 + 6}{30} = \frac{1}{30}$

(Verified)
(ii) $\frac{-3}{5}, \frac{7}{10}$ and $\frac{4}{15}$
Solution:
$\left(\frac{-3}{5} + \frac{7}{10}\right) + \frac{4}{15} = \left(\frac{-6 + 7}{10}\right) + \frac{4}{15} = \frac{1}{10} + \frac{4}{15} = \frac{3 + 8}{30} = \frac{11}{30}$

(Verified)
(iii) $\frac{3}{-7}, \frac{2}{21}$ and $\frac{-5}{14}$
Solution:
$\left(\frac{-9 + 2}{21}\right) + \frac{-5}{14} = \frac{-7}{21} + \frac{-5}{14} = \frac{-1}{3} + \frac{-5}{14} = \frac{-14 - 15}{42} = \frac{-29}{42}$
$\frac{-3}{7} + \left(\frac{4 - 15}{42}\right) = \frac{-3}{7} + \frac{-11}{42} = \frac{-18 - 11}{42} = \frac{-29}{42}$
(Verified)
(iv) $1, \frac{5}{-11}$ and $\frac{7}{22}$
Solution:
$\left(1 + \frac{-5}{11}\right) + \frac{7}{22} = \left(\frac{11 - 5}{11}\right) + \frac{7}{22} = \frac{6}{11} + \frac{7}{22} = \frac{12 + 7}{22} = \frac{19}{22}$
$1 + \left(\frac{-10 + 7}{22}\right) = 1 + \frac{-3}{22} = \frac{22 - 3}{22} = \frac{19}{22}$
(Verified)

$\left(\frac{2}{3} + \frac{-17}{3}\right) + \left(\frac{-11}{8} + \frac{3}{8}\right) = \frac{-15}{3} + \frac{-8}{8} = -5 - 1 = -6$
